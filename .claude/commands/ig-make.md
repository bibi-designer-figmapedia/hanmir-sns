description: 브리프(제품·주제·건수) → 회차별 콘텐츠 구성 → 피그마 틀 (ig-content-maker 실행)
argument-hint: [plan|make|all] 제품 / 주제·무드 / 건수
---

ig-content-maker 에이전트를 호출한다.

인자: $ARGUMENTS
- 첫 단어가 `plan`(기본) / `make` / `all` 이면 실행 범위. 나머지가 브리프.
  - `plan` — 회차별 기획서만 만들고 멈춘다 (A)
  - `make` — `outputs/planning/`의 최신 기획서대로 피그마 틀 생성 (B)
  - `all` — 기획부터 피그마까지 한 번에
- 브리프 예: `/ig-make plan 조거하네스 후르츠 에디션 / 가을 산책 루틴 / 4`
  제품이 없으면 `BRAND.md`의 "이번 달 밀 제품", 건수가 없으면 3.
- **브리프가 없거나 주제·무드가 빠졌으면** 에이전트를 부르기 전에 한 메시지로 묻는다 (제품 / 주제·무드 / 건수, 기본값 안내 포함). 답을 받은 뒤 호출한다. 에이전트가 되묻게 두지 않는다.

에이전트에 브리프와 `BRAND.md` 경로를 전달한다. `outputs/research/`에 최신 `*_competitor-report.md`가 있으면 **경로만** 함께 전달한다(없어도 진행).
`BRAND.md`의 `콘텐츠 제약`·`이미지 프롬프트 가이드`·`figma_template`이 `{…}`로 비어 있으면 호출 전에 채워달라고 한다.

완료되면 요약(기획서 경로 / 회차 수 / 피그마 링크 / 검수 요청)을 보여주고 **게이트 ②**에서 사용자 확인을 받는다.
그다음 "피그마에서 image 레이어 선택 → Make an image → 기획서 프롬프트 붙여넣기"를 안내한다.
